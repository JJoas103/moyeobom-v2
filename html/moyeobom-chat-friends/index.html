화면에 반영된 확정 규칙

  • 모임 채팅은 승인된 참여자만 입장 · 대화는 신고 확인용으로 서버 보관
  • 공지 고정은 호스트만 · 참여자는 읽기만
  • 메시지 신고 · 참여자 차단 (⋯ 메뉴)
  • 평가 열림: 이야기 자리 시작일 다음날 12:00 · 마감: 열림 + 48시간
  • 평가 대상: 같은 모임의 확정 참여자 (본인 제외)
  • 칭찬하기: 사람만 고름 · 매너 점수에 반영
  • 또 만나고 싶어요: 비공개 · 서로 골랐을 때만 '요청 가능'
  • 친구 성립: 요청 → 수락 · 거절 버튼 없음, 기한 지나면 조용히 만료
  • 두 사람이 동시에 요청하면 바로 친구
  • 일괄 버튼: 카드 1개여도 노출 · 확인 팝업 필수
  • 친구 메모: 본인만 보임 · 작은 팝업에서 입력
  • 종료 예정 시각 없음 (모든 화면에서 제거)

미결정 — 구현 전에 정해야 할 것

  • 요청 만료 기한 — 화면엔 7일(제안값)
  • 메모 글자 수 — 화면엔 30자(제안값)
  • 매너 점수 산정 방식 · 노출 위치 (화면에 숫자 없음)
  • 노쇼 판정 주체 (평가 화면에 항목 없음)
  • 모임 채팅방 유지 기간 · 대화 보존 기간
  • 공지 최대 개수
  • 알림 대상 이벤트 · 전달 수단
